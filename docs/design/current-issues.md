# 当前界面的实际问题(2026-09-14 看图记录)

依据:`app/tool/emu_room.png`(Android 真机 1080×2400 截图)。
不是凭描述,是看图数出来的。

## 房间页的七处硬伤

| # | 问题 | 性质 |
|---|---|---|
| 1 | 右上角 `RIGHT OVERFLOWED BY 2014 PIXELS` | **布局 bug**,不是审美问题 |
| 2 | 顶部甩出原始异常 `ClientException with SocketException: Connection...`,还被截断 | 把技术细节直接丢给用户 |
| 3 | 状态切换器(随时聊/在忙/耳朵在)**出现两次** —— 顶部一个半透明糊在标题上,底部一个 | 信息架构错误 |
| 4 | 底部三个灰圆按钮,挂断键是**浅蓝色** | 与品牌毫无关系 |
| 5 | 两个头像占顶部一小块,**下方三分之二全空** | 空间浪费 |
| 6 | 底部切换器是**亮色描边**,在深色界面上像从别的 app 粘来的 | 风格不统一 |
| 7 | 背景棕色渐变**浑浊**,不像"深夜暖调",更像褪色 | 色彩执行 |

## 最要命的一条

**品牌色 `#FF8A5C` 在整个界面上一次都没出现。**

`tokens.dart` 里定义了「余烬暖橙」,注释写着「语音波纹/主按钮」,
但实际界面上主按钮是灰的、挂断是浅蓝的、状态色是绿的。
设计系统与实现脱节。

## 与之相关的产品要求

用户明确要求(2026-09-14):
1. **前端要简洁** —— 回到之前那种克制感

   其中「状态(信令地址/进房耗时)」「服务器设置」明显是调试用的
3. **去调研怎么做得好看** —— 不要凭感觉改
