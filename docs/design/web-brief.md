# 官网设计纲要

> 内部文档。给实现者看的硬约束。
> 站点：<https://docs.laresapp.org>

## 一句话

**网站要看起来像这个 App 的延伸，而不是一个漂亮但无关的落地页。**

判断标准：把网站截图和 App 截图并排放，应该像同一个东西。

## 绝不能破坏的

这个站同时服务两类读者，后者是**上架的必要条件**：

| 读者 | 要什么 | 状态 |
|---|---|---|
| 潜在用户 | 这是什么、为什么该装 | 要做 |
| **App Store 审核员** | 隐私政策、条款、支持渠道 | **已有，不能弄坏** |

以下 URL **必须继续可达**，路径不能变（ASC 里已填、审核员会点）：

```
https://docs.laresapp.org/          首页
https://docs.laresapp.org/privacy   隐私政策
https://docs.laresapp.org/terms     服务条款
https://docs.laresapp.org/support   支持与反馈
```

同时这些**必须继续 404**（内部文档，不该公开）：

```
/app-store/*  /research/*  /design/*  /plans/*  /compliance/*
/l10n-guide  /available-protocol  /recording-consent-protocol
```

## 色板：直接取自 App

源文件 `app/lib/src/theme/tokens.dart`，**不要自己调色**。

```css
--bg:            #121016;  /* 深暖灰紫,不是死黑 —— 这个区别是刻意的 */
--surface:       #1C1922;
--surface-high:  #26222E;
--text:          #F2EEE9;
--text-dim:      #9A93A3;
--ember:         #FF8A5C;  /* 余烬色,全站唯一的暖色 */
--ember-soft:    rgba(255,138,92,0.2);

/* 状态色,仅在展示成员状态时使用 */
--status-free:   #6FD08C;  /* 随时聊 */
--status-busy:   #E8B45A;  /* 在忙 */
--status-ears:   #6FA8D0;  /* 耳朵在 */
```

### ember 橙只用在一处

`#FF8A5C` 代表「火」，是整个界面唯一的暖色。
**用在一处才有力量，铺满就廉价了。**

允许：Hero 里一个词、一个呼吸的光点、主按钮。
不允许：大面积色块、渐变背景、多个强调元素同时用它。

## 排版：有实证约束，不是偏好

`docs/design/ui-research.md` §3 引了 Ergonomics 期刊的研究，结论是硬的：

- **暗色背景下小字号的可读性损失最大**（Piepenbrock et al. 2014，
  正极性优势随字号减小而线性增大）
- **色相差不能替代亮度差**（Buchner & Baumgartner 2007）

因此：

| 项 | 要求 |
|---|---|
| 正文字号 | ≥ 16px（移动端 ≥ 17px） |
| 正文对比度 | **≥ 8:1**，不是 4.5:1 及格线 |
| 次要文字对比度 | ≥ 5:1 |
| 行高 | 正文 1.7，中文段落尤其需要 |

`--text-dim: #9A93A3` 对 `--bg: #121016` 是 6.6:1，做次要文字可以，
**不要用它写正文**。

## 语气：克制是这个产品的优势

App 里写「算了」而不是「取消」，写「耳朵在」而不是「仅收听」。
网站如果突然变成「革命性的语音体验」，就自己打脸了。

**禁用**：革命性、颠覆、无缝、强大、极致、完美、!（感叹号）
**参照**：现有 `docs/index.md` 的语气就是对的，可以直接复用那些句子

英文同理，见 `docs/l10n-guide.md` 的语气表。

## 不做的东西

- **玻璃拟态 / Liquid Glass** —— `ui-research.md` §2.2 已明确结论「Lares 不用」
- 视差滚动、鼠标跟随、粒子背景
- 自动播放视频
- Cookie 横幅（我们不用 cookie，别为了"看起来专业"加一个）
- 任何第三方分析脚本 —— 隐私政策里写着「不收集」，网站也必须做到

## 内容结构（首页）

按这个顺序，每屏一个意思：

1. **Hero** —— 一句话说清是什么 + 下载入口
   - 现有文案可用：「一个给熟人小圈子用的常驻语音房——进去就能说话，
     不说话也可以一直挂着，像围坐在火边。」
2. **它解决什么** —— 3 个点，配产品截图
   - 常驻（不是「发起通话」，是一直在那儿的房间）
   - 小圈子（口令进入，没有陌生人发现）
   - 可加密（密钥由圈口令派生，服务器也解不开）
3. **它不是什么** —— 这段现有文案很有力，保留
   - 「不是陌生人社交，不是匿名聊天。没有任何『发现附近的人』
     『随机连线』这类功能，代码里也不存在相关实现。」
4. **开源自托管** —— 服务器代码同仓库，App 里能填自己的地址
5. **页脚** —— 隐私 / 条款 / 支持 / GitHub

⚠️ **截图位先留占位。** 真机截图要等 TestFlight 装上才有，
那批图 App Store 也要用，会一次拍两用。占位不要用 Lorem，
用一个带 `--surface` 底色、标注「截图待补」的方块。

## 技术约束

- **Astro**，输出纯静态
- **零客户端 JS**（除非某个交互确实必要，且必须能优雅降级）
- 深色为默认；亮色模式可做可不做，但**不要做一半**
- 中英双语：App 已经双语了，网站至少 Hero 和三个卖点要有英文
  （App Store 主语言是 English）
- 字体用系统栈，不加载 Web Font ——
  中文字体动辄几 MB，而我们的用户在意的是隐私不是衬线

## 验收

```
1. 四个必须可达的 URL 全部 200
2. 内部文档路径全部 404
3. Lighthouse:性能 ≥ 95,可访问性 = 100
4. 正文对比度实测 ≥ 8:1
5. 移动端 375px 宽不横向滚动
6. 关掉 JS 站点完全可用
7. 无任何第三方请求(打开 DevTools Network,应只有本域)
```
