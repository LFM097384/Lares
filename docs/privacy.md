# 隐私政策

最后更新：2026-10-03

这份政策描述 **Lares 炉灵**（以下简称「本应用」）如何处理你的信息。
它是按代码的**实际行为**写的，不是模板。每一条都能在
[源代码](https://github.com/LFM097384/Lares)里查证。

## 一句话

本应用**没有账号体系**，不收集你的手机号、邮箱、通讯录或位置历史。
不接入任何分析、广告或崩溃上报 SDK。

## 一个重要前提：服务器可能不是我们的

本应用是**自托管**的。你连接的服务器可能是：

- 你自己或你朋友搭建的（我们对它没有任何访问权限）
- 我们提供的默认服务器

**下文所说的「服务器」指你实际连接的那一台。**
如果它是你自己搭的，那么下述所有数据都只存在于你自己的机器上。

## 本应用处理哪些信息

### 存在你设备上（不上传）

| 数据 | 用途 |
|---|---|
| 昵称 | 让圈友知道是你 |
| 设备标识（本地随机生成） | 区分同一个人的不同设备 |
| 圈子列表与口令 | 进入你的圈子 |
| 各项设置 | 降噪、免打扰等偏好 |

圈子口令与服务器令牌保存在**系统级安全存储**中
（iOS/macOS Keychain、Android Keystore、Windows DPAPI）。

### 会经过服务器

| 数据 | 是否存储 | 说明 |
|---|---|---|
| 语音 | **否** | 实时转发，不录制、不落盘 |
| 文字与图片消息 | **否** | 走媒体通道直接转发，不经过信令服务器 |
| 在线状态、昵称 | **仅内存** | 断开即消失 |
| 位置共享（需你主动开启） | **仅内存** | 只转发给同房成员，关闭或断连即删 |
| **语音便签** | **是** | 见下 |
| 插件共享状态（圈主装了插件时） | **是** | 服务器可见，含加密圈，见「插件」 |
| 专注时长（圈主开了专注学习时） | **是** | 按天累计，用于排行榜，见「专注学习」 |
| 连续打卡天数、每周小结（专注学习开着时） | **是** | 按圈按人，见「专注学习」 |
| 推送设置（每圈「通知我」等级、免打扰时段、时区偏移） | **是** | 随推送登记保存，关掉推送即删，见「活动推送」 |
| 实时字幕的识别凭证 | **否** | 服务器只代为向阿里云申请一次性临时凭证，不经手音频和文字，见下 |

### 语音便签是唯一会落盘的内容

圈里没人时可以留一段不超过 15 秒的语音，等下一个人进来听。
这段音频会**保存在服务器磁盘上**，与你的昵称和用户标识存在同一条记录里。

设计上是「听过即删」，但在没人听的情况下会一直保留。
如果你不希望留下任何录音，不要使用这个功能。

### 实时字幕会把你的语音送到阿里云识别

房间里有人打开「字幕」（比如他此刻不方便外放）时，**你自己**的设备会把
**你自己**的麦克风声音实时发送到阿里云（DashScope 语音识别，北京地域），
识别出的文字只发给打开了字幕的那几个人。只在以下条件**同时**满足时才发生：

- 房里至少有一个别人打开了字幕；
- 你在房间里，且麦克风开着、确实在发声音（静音即停，1 秒内断开连接）；
- 你没有在设置里关掉「有人需要字幕时，识别我的语音」（默认开）；
- 若圈子开了端到端加密，你还额外打开了「加密的圈子也用云端识别」（默认关）。

发生期间界面顶部会一直显示「正在为 X 生成字幕 · 语音经阿里云识别」，
点一下就在本次停止。只识别你自己的声音，从不识别别人的。

- 本应用和服务器**都不保存**音频或字幕文字；字幕只在接收者的屏幕上显示最近几十行，
  关掉即清空，不写入磁盘。
- 字幕文字走与聊天相同的媒体数据通道；开了端到端加密的圈子里，字幕文字也是加密的。
- 音频到达阿里云后，由阿里云按其隐私政策和服务条款处理。**我们无法控制阿里云是否留存**。
- 你的服务器只负责向阿里云申请一个一分钟左右有效的临时凭证交给你的设备，
  并做频率限制；它不接触音频或文字。自托管的服务器不配置阿里云密钥时，此功能整体不出现。

### 转写记录（圈主开启）

注册圈的圈主可以为整个圈子打开「转写记录」，默认关。打开后，成员说的话会经上面同一条
阿里云语音识别链路变成文字，每一句定稿的文字**连同说话人的昵称和用户标识**会被保存下来，
圈子里的人可以在「转写记录」里回看。

- **普通圈子**：文字保存在**服务器**上，直到圈主「清空记录」或圈子被删除。
- 识别只发生在你自己的设备上、只识别你自己的声音。不想被记录的成员，
  在设置里关掉「有人需要字幕时，识别我的语音」即可——你的声音就不会被识别，也就不会进入记录。
- 圈主「清空记录」后，服务器上的记录被删除，并通知所有在线成员清掉本机缓存。

### 加密圈里的转写记录

端到端加密的圈子里开启转写记录时，圈主会先看到一道说明：语音仍要送到阿里云识别。
识别出的文字在你的设备上用**由圈口令派生的密钥**加密（AES-256-GCM），
服务器只**转交它看不懂的密文**：

- 密文为不在线的成员排队，最多保留 **30 天、5000 条**；成员设备收到并确认后立即从服务器删除。
- 记录**保存在每位成员自己的设备上**（应用文档目录），卸载应用即删除；
  圈主清空记录时，会通知各成员设备删除本机记录。
- 没有圈口令的设备解不开这些密文。

### 机器人（外部程序访问）

注册圈的圈主可以创建「机器人令牌」，交给自己信任的外部程序（例如会议纪要工具）。
持有令牌的程序可以**读取该圈的转写记录、实时收到圈里的事件，并以「机器人」身份
向聊天发消息、发字幕、在房间里播放一段语音**（不超过 60 秒）；它发出的内容在界面上
带「机器人」标记，冒充不了成员。它不会收到成员的原始音频。
令牌只在创建时显示一次；圈主可以随时吊销，吊销立即生效（包括正在进行的连接）。
端到端加密的圈子里，服务器看不懂内容，机器人既读不到也发不了消息。

### 插件（圈主安装）

注册圈的圈主可以为圈子安装插件。插件分两种，可以兼有：

- **服务端插件（webhook）**：圈主安装时会看到它要哪些权限。安装后，服务器会把圈主
  允许的那几类事件（例如谁进出房间、在线状态、转写记录、插件状态、专注事件）**发送到插件作者
  指定的第三方网址**，并给它一个与机器人同等能力的令牌。**这些数据从此由插件作者处理，
  不受本政策约束**；只安装你信任的插件。卸载插件即停止发送并吊销令牌。
- **网页小程序**：插件可以提供一个网页，在房间里以内嵌网页打开。**第一次打开时，
  每位成员自己会看到一页说明**，列出它要的权限和来源网址，你可以选「算了」。
  网页能拿到的东西严格受这些权限限制（例如读成员昵称、发一条聊天）；它运行在网页沙箱里，
  本应用**不下载、不执行任何原生代码**。
- **插件的共享状态**（例如一个计数器、番茄钟的倒计时）**保存在服务器上，服务器能看到**——
  即使圈子开启了端到端加密也是如此，加密只覆盖语音、聊天与字幕。同意页会明确提示这一点。
- 插件的本地存储只存在你自己的设备上，按圈子和插件隔离。

### AI 助手（圈主开启）

圈主可以为圈子打开「AI 助手」。打开后：

- 助手是房间里一个**看得见的成员**，有自己的名字；它说的话同时出现在字幕和聊天里。
- 房间里成员**正在说话**时，语音会实时发送到阿里云（DashScope，北京地域）做语音识别；
  识别出的文字（连同说话人的昵称）和助手的回复文字会发送到 DashScope 生成回答、合成语音。
  这些数据到达阿里云后由阿里云按其政策处理，**我们无法控制阿里云是否留存**。
- 关掉了「有人需要字幕时，识别我的语音」的成员，只要助手能看到这个偏好，
  他的声音就**不会**被送去识别。
- 端到端加密的圈子里，服务器无法运行助手；只有当某位知道圈口令的人在自己的机器上
  带着口令运行它时，助手才会出现在加密圈里——此时语音同样会送到阿里云。
- 服务器**不保存**音频、识别文字或对话内容，只保存用量计数（每天回答了多少次等），用于限制费用。
- 圈主停用或卸载插件，助手立即离开。
- 圈子打开 AI 助手后，成员下次进圈会看到一次隐私告知，其中单独一行写明「AI 助手开」及语音会发到阿里云百炼 DashScope；
  房间「更多」里的「AI 助手」也随时说明它叫什么、怎么叫它。客户端不允许在端到端加密的圈里由圈主开启它。

### 专注学习（圈主开启）

圈主可以为圈子打开「专注学习」。打开后，在这个圈子的房间里：

- 你的应用会在你**离开应用超过一段宽限时间**（默认 10 秒，圈主可调）时告诉服务器
  「离开了」以及大约何时离开，回来时告诉「回来了」。**只上报离开/回来这两件事，
  不上报你去了哪个应用、做了什么**。在 iOS 上锁屏和来电也会被算作离开（系统不区分）。
- 圈里的人会看到你的专注状态（「专注中」「离开 2:13」）和「X 离开了 3 分钟」这样的提示。
- 服务器按圈保存每位成员的**累计专注时长**（按天汇总，保留约 60 天，另有总计），
  用于排行榜；圈子被删除时一起删除。
- Android 上的「锁定专注」使用系统的屏幕固定功能，需要你确认，随时可以用系统手势退出。
- 每轮番茄钟结束，房里的人会看到一张出勤卡（「3/4 全勤 · 小鹿离开 2 分钟」）——
  **谁离开了多久对同房的人可见**。
- 服务器按圈保存每位成员的**连续打卡天数**（完成过一轮番茄钟的连续天数），显示在座位和排行榜上；
  每周一生成一份**上周小结**（你的专注时长、圈内名次、连续天数、全圈总时长），
  只给你本人看（推送 + 下次进圈时的卡片），看过即标记。AI 助手不计入任何统计。

### 活动推送（会暴露「谁在」）

推送是为了让你知道圈里有动静。为此服务器会给**不在房里**的圈成员发这样的通知：

- 「阿蛮开始专注了，一起学?」（有人开始专注 / 学习圈有人第一个进房）
- 「圈里已经有 3 个人在聊」（房里人数达到圈主设定的人数，每次开房一次）
- 「小鹿来了」（有人走进空房间；默认关）
- 「X 叫你来圈里」（圈主手动「叫大家来」，每圈 10 分钟一次）
- 每周一的专注小结

**这意味着：别人开始专注、进房、在线人数这些「在场信息」会通过通知传给圈里的其他人，
并且会经过 Apple 推送服务（APNs）。** 加密圈的通知不带圈名。

你可以控制：每个圈的「通知我」选 全部 / 只要被叫 / 关；全局「推送免打扰」时段
（默认 23:00–08:00，按你手机上报的时区偏移算，所以服务器会保存这个偏移）。
另有防骚扰上限：同一个圈 30 分钟内最多一条、每天最多 8 条；正在房里或 5 分钟内刚离开的人不会收到。
圈主可以关掉任意触发器。

### 圈子的功能开关（圈主设置）

除了语音和文字聊天（永远开着），其他能力都由注册圈的圈主按圈开关。和隐私有关的几项：

| 功能 | 打开后数据去哪 |
|---|---|
| 实时字幕 | 有人开字幕时，你的语音片段送阿里云识别（见上），不保存 |
| 转写记录 | 语音经阿里云识别，文字存服务器；加密圈服务器只转交密文（见上） |
| 语音便签 | 音频存服务器磁盘（见上） |
| 位置共享 / 地图 | 只在你自己打开时，经服务器内存转发给同房成员 |
| 录音 | 录音时房里每个人都会看到提示 |
| 插件 | 服务端插件会把事件发到第三方网址（见「插件」） |
| 专注学习 | 离开/回来事件与专注时长存服务器（见「专注学习」） |
| 点对点直连 | 语音直接在成员设备之间传，对方设备能看到你的网络地址 |

**新建的圈子默认关掉**位置共享、录音、点对点直连和开发者读数；字幕、语音便签、插件默认开，
转写记录默认关。功能关掉时服务器会拒绝相应的请求，而不只是界面上藏起来。
此前就存在的老圈子保持原来的行为（全部开着），直到圈主去改。

### 用途预设

圈主可以给圈子选一个「用途」（例如闲聊、学习、开会，或别人分享的自定义用途）。
用途只是一组功能开关、插件和圈设置的打包，一键应用——**应用一个用途可能会打开转写记录、
安装插件**。这是圈主的操作；成员不会被悄悄改变处境，下一次进圈时会看到下面这页说明。

### 进圈时的隐私说明

你加入或进入一个圈子、本机第一次拿到它的完整设置时，会弹一页「本圈的隐私设置」，
一行一件事：转写记录开没开、字幕是否可用、启用了哪几个插件（各要什么权限、会不会把数据发给第三方）、
专注追踪、位置共享、是否端到端加密。点「知道了」或划掉之后，再进同一个圈不再弹。

- 本机会把这几项**算成一个指纹**：转写、字幕、启用的插件（插件 id、权限、是否服务端插件，
  不含插件名）、专注、加密规定、录音、地图。圈主改了其中任何一项，指纹就变，你下次进圈
  （或人在房里时设置一变）会再看到一次。
- 「看过哪个指纹」**只存在你自己的设备上**，从不发给服务器；把圈子从本机拿掉时一起删除。
- 圈主本人不弹（设置是他自己定的）。

## 端到端加密

圈子可以开启端到端加密。开启后，密钥由**圈口令派生**（Argon2id），
**从不上传服务器**。服务器只能转发密文。

开启加密的圈子里，服务器无法转录、无法做任何内容处理。
实时字幕在加密圈里默认不启用：它需要把你的声音送到阿里云，
这与「语音不出手机」的承诺冲突，只有你明确打开相应开关才会启用（见上）。
本应用会在界面上如实显示当前是否真的加密——
若你的平台不支持加密，会明确告知，**不会假装已加密**。

## 权限

| 权限 | 什么时候用 | 能不能拒绝 |
|---|---|---|
| 麦克风 | 你开麦说话时 | 可以，但就没法说话了 |
| 位置 | 仅当你主动开启位置共享 | 可以，不影响其他功能 |

本应用**不访问**相册、通讯录、相机。发图片走的是系统文件选择器，
只能拿到你亲自选中的那一个文件。

## 我们不做的事

- 不出售、不共享你的数据给第三方
- 不做用户画像、不做跨应用追踪
- 不接入任何第三方分析或广告 SDK
- 不要求注册，不收集身份信息

## 第三方服务

- **地图底图**：开启位置共享时，地图图块来自 [OpenStreetMap](https://www.openstreetmap.org/copyright)
- **更新检查**：向 GitHub 查询最新版本号
- **实时字幕与转写记录的语音识别**：阿里云 DashScope（qwen3-asr-flash-realtime），仅在上文所述条件下使用
- **AI 助手**：阿里云 DashScope 的语音识别、大模型与语音合成，仅在圈主开启 AI 助手时使用（见上）

## 儿童

本应用不面向 13 岁以下儿童设计，也不会有意收集他们的信息。

## 你的选择

- 卸载应用即清除设备上的全部本地数据
- 退出圈子即停止一切数据交换
- 在设置里关掉「有人需要字幕时，识别我的语音」，你的声音就永远不会被送去识别
- 如果服务器是你自己的，你对上面所有数据拥有完全控制权
