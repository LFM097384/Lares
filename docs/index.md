# Lares 炉灵

宅火的守护神，随人而动。

一个给熟人小圈子用的**常驻语音房**——进去就能说话，不说话也可以一直挂着，
像围坐在火边。支持 iOS / Android / Windows / macOS / Web。

**开源自托管**：服务器代码在同一个仓库里，你可以跑在自己的机器上。
App 里能填自己的服务器地址。

## 它是什么

- **常驻**——不是「发起通话」，是一个一直在那儿的房间
- **小圈子**——靠圈子口令进入，没有陌生人发现、没有随机匹配、没有公开房间列表
- **无账号**——不需要注册，不收集手机号邮箱
- **可加密**——圈子可以开启端到端加密，密钥由圈口令派生，服务器也解不开

## 它不是什么

不是陌生人社交，不是匿名聊天。没有任何「发现附近的人」「随机连线」这类功能，
代码里也不存在相关实现。
