# 支持与反馈

## 遇到问题？

- **公开的问题与建议**：[GitHub Issues](https://github.com/LFM097384/Lares/issues)
- **举报、隐私请求、不便公开的事**：**support@laresapp.org**

提问题时带上这些会快很多：

- 用的哪个平台（iOS / Android / Windows / macOS / Web）
- 应用版本（设置页最下面）
- 连的是自己的服务器还是默认服务器

## 举报滥用行为

应用内成员头像**轻点或长按**、消息**长按**都有「举报」。
它会生成一封写好的邮件，你确认后发送即可。

我们承诺 **24 小时内**处理。

如果只是不想再看到某个人，用**屏蔽**更快——
它立刻静音对方并隐藏其消息，不需要等我们处理。

## 常见问题

### 进不去圈子

多半是口令不对。到设置页检查该圈子的口令，那里有「测试连接」按钮，
能当场告诉你是口令错了还是连不上服务器。

### 挂着的时候掉线了

常驻语音房需要保持后台运行。设置页有「后台运行保障」，
按提示允许后台运行与关闭电池优化。

### 听不见对方 / 对方听不见我

先确认双方都没静音。若圈子开了**端到端加密**，
双方的圈口令必须完全一致——差一个字符就互相解不开，
表现正是「连上了但听不见」。

### 图标显示「没加密」但我开了加密

这是**故意的**。开关打开不等于真的加密：
你的平台可能不支持，或者这个圈子还没有口令。
界面会如实显示，而不是假装已加密——
在安全功能上，含糊的状态展示本身就是缺陷。

### 想用自己的服务器

设置页连点版本号 7 次打开开发者模式，里面有「服务器与口令」。
服务器代码在[仓库](https://github.com/LFM097384/Lares)的 `server/` 目录。

## 隐私相关请求

要求删除数据或询问数据处理方式，请开 Issue 并在标题注明「隐私」。

注意：语音便签是唯一会存在服务器上的内容。
如果你连的是自己的服务器，数据在你自己手里，我们无法也无需干预。
